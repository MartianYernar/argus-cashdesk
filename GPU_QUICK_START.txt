ARGUS: запуск на ноутбуке с GPU (Windows)

1. Распаковать архив. В этой папке должны быть backend/, dist/ и start-public.ps1.
2. Убедиться, что Ollama уже запущена и ollama list показывает qwen3.5:4b.
3. Открыть PowerShell в распакованной папке и выполнить:
   powershell -ExecutionPolicy Bypass -File .\start-public.ps1
4. Скрипт покажет секретный API key и публичный адрес https://....trycloudflare.com.
   Web interface URL = этот адрес.
   API base URL = этот же адрес (без /api/v1).
   API key = строка, которую напечатал скрипт.
5. В другом окне PowerShell из той же папки:
   powershell -ExecutionPolicy Bypass -File .\test-public.ps1 -Url "https://ВАШ-АДРЕС.trycloudflare.com" -Video "C:\путь\Х-3.mov"
6. Передайте результат теста и адрес владельцу проекта. Ключ передавайте только своей команде/жюри.

Сайт доступен локально http://127.0.0.1:8000 и по публичному адресу.
В публичном сайте нажмите «Сервер подключён» и введите ключ в настройках.
В локальном сайте ключ подставляется автоматически.
Ollama не публикуется: туннель ведёт только на порт 8000.
Обработка остаётся на этом ноутбуке. HTTPS-запросы и ответы проходят через Cloudflare как транспорт; облачные ИИ не используются.
Публичный URL временный и меняется после перезапуска. Не закрывать окно и не выключать ноутбук до проверки жюри.
Нужны Python 3.12+ и интернет для зависимостей/туннеля; Node.js не нужен, сайт уже собран.
Детектор из финального архива сохранён без изменений. Ничего не переобучается.
