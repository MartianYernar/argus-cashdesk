        06
        
API

        
Два шага: загрузить видео и забрать результат. Ключ — в заголовке X-API-Key.

      

      

        

          
routes06

          

            
POST /api/v1/analyze
multipart поле file (.mov) → job_id

            
GET  /api/v1/jobs/{job_id}
processing · done · failed + результат

            
HDR  X-API-Key: <key>
без ключа → 401
